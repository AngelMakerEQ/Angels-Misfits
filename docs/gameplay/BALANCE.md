# Balance

## Status

No standalone balance program is currently active. Player-facing tuning that
has been deliberately adopted is documented in the applicable ADR or gameplay
reference: server pacing and death rules in ADR-002, NPC combat values in
ADR-003, pet values in ADR-005, and current mechanics work in
`docs/development/MECHANICS_REVIEW.md`.

Add this document only when a cross-system balance decision needs analysis that
does not belong to one of those authoritative records.
