# Custom Tables

No custom tables have been introduced to the Angels Misfits database
as of this writing. All changes documented in `PEQ_CHANGES.md` and
`TAKP_IMPORTS.md` modify existing PEQ-standard tables
(`rule_values`, `npc_types`, `spells_new`, `starting_items`).

This document will be populated if and when a custom system requires
its own table, per the project's stated preference for using existing
EQEmu/PEQ structures before introducing new ones (see
`DESIGN_PHILOSOPHY.md`, Customization Philosophy).
