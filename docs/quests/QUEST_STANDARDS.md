# Quest Standards

## Status

Quest scripting is not active development. Until it is, preserve PEQ-compatible
data and script conventions, prefer existing EQEmu systems before custom logic,
and record gameplay-affecting decisions in an ADR.

Epic 1.0 verification is complete and tracked separately in
`docs/gameplay/EPIC_QUESTS_REVIEW.md`; it is a verification record, not a new
quest-scripting standard.
