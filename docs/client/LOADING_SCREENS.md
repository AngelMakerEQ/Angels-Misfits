# Loading Screens

## Current State

Unresolved. RoF2 currently displays RoF2-era expansion loading screen art rather than Classic/Kunark/Velious-era art.

## Correction to an Earlier Assumption

Classic-era EverQuest **did** have its own loading screen art (a distinct "Classic" loading screen existed alongside Kunark, Velious, and every later expansion) — this is not a modern-only feature. The goal here is Classic/Kunark/Velious-era loading screen art specifically, not the absence of loading screens.

## Available Options

### Option 1 (Fallback): Disable Loading Screens Entirely

Available via the in-game options menu. Results in a plain loading bar over whatever was last rendered on screen, rather than any splash art. This is a quality-of-life/preference choice, not a historically-accurate restoration — flagged here so it isn't mistaken for the latter later.

### Option 2 (Preferred, Unverified): Replace Loading Screen Art Files

A community method for replacing loading screen splash art with custom images (including era-appropriate art) has been referenced in community discussion, but **the specific walkthrough found for this has not yet been tested or verified** against the current RoF2/AddictedDads client setup. Treat as unconfirmed until tried.

## Next Step
