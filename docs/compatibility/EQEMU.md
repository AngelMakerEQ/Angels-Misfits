# EQEmu Compatibility

## Status

Angels Misfits uses stock PEQ-compatible schema, an EQEmu Windows Installer
deployment, and the supported RoF2 client. Prefer existing EQEmu systems,
database configuration, and server rules before quest or source changes; this
keeps the project compatible with upstream tooling and future maintenance.

Operational details are in `docs/development/MCP_USAGE.md`; architecture is in
`docs/architecture/SERVER_ARCHITECTURE.md`.
